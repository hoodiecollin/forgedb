# Archive

This directory contains historical documentation from the ForgeDB development process.

## Structure

### `planning/`
Original design specifications created before implementation began:
- **DSL_SPECIFICATION.md** - Schema language design
- **STORAGE_ARCHITECTURE.md** - Storage system architecture
- **API_GENERATION.md** - REST API generation plans
- **CLI_SPECIFICATION.md** - CLI tool specification
- **ADVANCED_FEATURES.md** - Future feature proposals
- **COMPLETE_INTEGRATION.md** - Integration architecture
- **ORCHESTRATOR.md** - Sprint orchestration system

### `sprint-summaries/`
Implementation summaries from completed sprints:
- **Sprint 2** - Persistence, types, and validation
- **Sprint 3** - Indexing and query operations
- **Sprint 4** - Relations and foreign keys
- **Sprint 5** - CLI, scaffolding, watcher, constraints, advanced indexes

## Purpose

These documents are preserved for:
- Historical reference
- Understanding design decisions
- Comparing initial plans vs final implementation
- Future feature planning
